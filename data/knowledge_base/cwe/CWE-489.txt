CWE-489: Active Debug Code

Abstraction: Base

Applicable Platforms: Not Language-Specific, Not Technology-Specific, ICS/OT

## Description
The product is released with debugging code still enabled or active.

## Common Consequences
- Confidentiality, Integrity, Availability, Access Control, Other: Bypass Protection Mechanism, Read Application Data, Gain Privileges or Assume Identity, Varies by Context — Active debug code can create unintended entry points or expose sensitive information. - [Build and Compilation, Distribution] Remove debug code before deploying the application.
